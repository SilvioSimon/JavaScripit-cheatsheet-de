JavaScript DOM Lernübersicht

1. Element auswählen
- getElementById() → HTML-Element über ID finden
- querySelector() → Element mit CSS-Selektor finden
- querySelectorAll() → mehrere Elemente auswählen

2. Inhalt ändern
- innerHTML → HTML-Inhalt lesen und verändern
- textContent → reinen Text verändern

3. CSS Klassen bearbeiten
- classList.add() → CSS-Klasse hinzufügen
- classList.remove() → CSS-Klasse entfernen
- classList.toggle() → CSS-Klasse ein-/ausschalten
- classList.contains() → prüfen, ob Klasse vorhanden ist

4. Attribute bearbeiten
- setAttribute() → Attribut ändern oder hinzufügen
- getAttribute() → Attribut auslesen
- removeAttribute() → Attribut entfernen

5. HTML Elemente erstellen und entfernen
- createElement() → neues HTML-Element erstellen
- appendChild() → Element hinzufügen
- remove() → Element entfernen

6. Events (Benutzeraktionen)
- onclick → Klick erkennen
- addEventListener() → moderne Event-Verarbeitung
- keydown → Taste gedrückt
- keyup → Taste losgelassen
- focus → Element ausgewählt
- change → Wert geändert

7. Formulare
- value → Eingabewert auslesen
- checked → Checkbox prüfen

8. CSS mit JavaScript verändern
- element.style → CSS direkt ändern
